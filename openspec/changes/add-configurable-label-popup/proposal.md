## Why

Сейчас расширение показывает только зашитый список Conventional Comments labels. Пользователь не может подстроить labels под командные договоренности, локализацию или личные обозначения, хотя именно текст label вставляется в комментарий и должен быть настраиваемым.

## What Changes

- Добавить browser action popup с настройками списка labels.
- Показать в popup все стандартные labels Conventional Comments: `praise`, `nitpick`, `suggestion`, `issue`, `todo`, `question`, `thought`, `chore`, `note`.
- Разрешить пользователю редактировать текст каждого label, включая emoji или полностью другое слово.
- Разрешить удалять labels из списка.
- Разрешить добавлять новые labels в список.
- Сохранять пользовательский список между сессиями браузера.
- Использовать сохраненный список для панели labels в GitHub Pull Request review comments.
- Сохранять дефолтное поведение для новых пользователей: если настроек еще нет, панель показывает стандартный список labels.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `github-review-comments`: панель labels должна использовать пользовательский настраиваемый список, а расширение должно предоставлять popup для управления этим списком.

## Impact

- `manifest.json`: добавить `action` popup и permission для хранения настроек.
- Новые файлы popup UI: HTML, CSS и JavaScript без сборщика и внешних зависимостей.
- `src/content-script.js`: заменить статический список на загрузку labels из Chrome storage с дефолтом и обновлять panel по сохраненному списку.
- `src/content-style.css`: при необходимости сохранить текущую компактную стилизацию панели.
- `test/`: обновить static tests под popup/storage и добавить поведенческие тесты для пользовательских labels, дефолта и пустого списка.
- `README.md`: обновить русскоязычную документацию по настройкам popup.
