## Why

Сейчас стили панели labels зашиты в расширение и одинаковы для всех сайтов. Пользователю нужен доступ к исходному CSS в настройках профиля, чтобы адаптировать оформление под сайт и легко вернуть стандартный вид.

## What Changes

- Добавить в каждый встроенный профиль блок «Стили панели» с редактируемым полным CSS, изначально заполненным нашими стандартными стилями панели и кнопок.
- Автоматически сохранять CSS отдельно для каждого профиля и применять его к панелям соответствующего сайта.
- Добавить в блок кнопку «Восстановить»: она сбрасывает только стили выбранного профиля, сохраняя остальные настройки и стили других профилей.
- Назвать существующий полный сброс «Восстановить профиль» и включить стили в полный сброс.
- Сохранить стандартное оформление для установок без пользовательского CSS.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `options-page`: редактор CSS, автосохранение и независимое восстановление стилей выбранного профиля.
- `site-profiles`: хранение и применение CSS выбранного профиля, стандартные значения и очистка при смене активного профиля.

## Impact

Затрагиваются `src/options.html`, `src/options.css`, `src/profile-settings.js`, `src/site-profiles.js`, `src/content-script.js`, `src/content-style.css` и подключение ресурсов в `src/background.js`/`manifest.json` при необходимости. Потребуются обновления тестов, README и документации профилей. Новые зависимости и сборщик не нужны. Настройка внешнего вида popup, страницы настроек и уведомлений диагностики не входит в изменение.
