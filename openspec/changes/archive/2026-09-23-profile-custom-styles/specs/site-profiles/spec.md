## ADDED Requirements

### Requirement: Стили панели в профиле сайта

Каждый встроенный профиль SHALL хранить независимое переопределение CSS панели между запусками браузера. Отсутствие переопределения SHALL использовать стандартный CSS текущей версии расширения. Существующие установки без CSS SHALL сохранять прежнее оформление и допустимые настройки профилей. Пустая строка SHALL отличаться от отсутствующего переопределения. Обновление расширения SHALL NOT заменять пользовательский CSS стандартным.

#### Scenario: Обновление прежней установки
- **WHEN** расширение читает профиль без настройки CSS
- **THEN** используются стандартные стили без потери адреса, масок, селектора, положения, labels и темы

#### Scenario: Сохранённый CSS после перезапуска
- **WHEN** браузер перезапускается с пользовательским CSS профиля
- **THEN** к панелям соответствующего профиля применяется сохранённое оформление

### Requirement: Жизненный цикл стилей профиля

Расширение SHALL применять CSS только активного профиля на подходящих страницах при наличии доступа. Сохранение и восстановление стилей SHALL обновлять уже открытые панели в доступных документах без перезагрузки страницы и без изменения текста комментария. При смене активного профиля, выходе за маску или отзыве доступа устаревшие стили SHALL удаляться вместе с собственным UI в доступных контекстах. Стандартные правила панели SHALL заменяться пользовательским CSS, а не оставаться скрытым слоем под ним. Стили диагностики SHALL оставаться отдельными от редактируемых стилей панели.

#### Scenario: Изменение при открытом редакторе
- **WHEN** пользователь сохраняет CSS при двух открытых редакторах соответствующего профиля
- **THEN** обе панели получают новый CSS без дублирования панелей и изменения комментариев

#### Scenario: Переход между страницами
- **WHEN** SPA-переход делает текущий профиль неприменимым или выбирает другой профиль
- **THEN** CSS прежнего профиля удаляется и применяется CSS нового профиля, если он выбран

#### Scenario: Восстановление стандартов
- **WHEN** пользователь восстанавливает стили выбранного профиля
- **THEN** открытые панели этого профиля получают стандартное оформление текущей версии расширения
