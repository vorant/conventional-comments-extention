## Why

Текущий README объединяет пользовательскую инструкцию, разработку и миграции, содержит устаревшие русские подписи интерфейса и не имеет скриншотов. После перевода расширения на английский нужны краткая пользовательская документация и согласованный текст для Chrome Web Store.

## What Changes

- Перенести всё существующее содержимое README.md в README-DEVELOPER.md без потери разделов и технических подробностей.
- Написать новый README.md на английском: назначение расширения, вставка префикса при ревью, управление labels и подключение корпоративного сайта через встроенный профиль.
- Добавить ссылку и атрибуцию оригинальной идеи Conventional Comments: https://conventionalcomments.org/.
- Снять английский интерфейс установленного расширения: панель в ревью, popup и настройки корпоративного сайта; добавить изображения и доступные описания в README.
- Подготовить отдельный лаконичный английский текст docs/chrome-web-store-description.txt для вставки в магазин, без маркетингового перечисления преимуществ.
- Сохранить честные границы поддержки: GitLab/Bitbucket — предварительные профили, совместимость корпоративных редакторов требует проверки; это настройка браузера пользователя, а не установка кода в репозиторий.
- Обновить существующую проверку README и документационные файлы в ZIP, чтобы локальные ссылки и изображения не ломались после распаковки.

## Capabilities

### New Capabilities

Нет: изменение документационное, skip_specs: true.

### Modified Capabilities

Нет: поведение расширения и существующие контракты остаются прежними.

## Impact

README.md, новый README-DEVELOPER.md, docs/chrome-web-store-description.txt, изображения в docs/screenshots/, технический протокол съёмки, Makefile и существующий documentation-тест в test/static.test.js. Исходный код расширения, manifest, разрешения и хранилища не меняются. Публикация в магазине, загрузка материалов в аккаунт и рекламные баннеры не входят в scope.
