## Why

Пользователь хочет пользоваться существующим Conventional Comments в Firefox. Сейчас пакет ориентирован на Chrome service worker; после добавления Safari нужен отдельный воспроизводимый Firefox-пакет с проверенной локальной установкой.

## What Changes

- Добавить `npm run package:firefox`, создающую `dist/firefox` из общих ресурсов с Firefox manifest и стабильным add-on ID.
- Адаптировать запуск фонового контекста и обращения к WebExtensions API без изменения пользовательского поведения Chrome и Safari.
- Обеспечить существующие панель комментариев, popup, labels, эмодзи, цвета, тему, настройки профилей и CSS в Firefox desktop.
- Документировать временную установку через `about:debugging`, обновление пакета, разрешения и ограничения сохранности данных после удаления.
- Добавить проверки упаковки, совместимости API и ручную проверку в Firefox с фиксацией версии браузера и ОС.
- Подпись, AMO, постоянная установка, Firefox Android, новые редакторы и перенос настроек между браузерами не входят в изменение.

## Capabilities

### New Capabilities
- `firefox-local`: существующий рабочий процесс расширения в локальной временной установке Firefox desktop.

### Modified Capabilities
- `extension-packaging`: отдельный воспроизводимый Firefox-пакет и инструкция временной установки.

## Impact

Затрагиваются manifest производного пакета, новый packaging script, `package.json`, фоновая инициализация, обращения к API в общих скриптах и порядок их загрузки, тесты и документация. Общие ресурсы и данные сохраняют текущую структуру; исходный Chrome manifest остаётся точкой входа unpacked-установки. Новые зависимости и сборщик не требуются. Основной целевой стенд — Firefox desktop на доступной macOS; другие ОС и старые версии не объявляются проверенными без фактического запуска.
