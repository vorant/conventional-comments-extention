## Why

Одинаковые кнопки labels трудно различать при ревью. Пользователь хочет стандартную палитру по предоставленному примеру и возможность выбрать свой цвет для каждого label прямо в popup.

## What Changes

- Добавить цветной образец и пикер в каждую строку label в popup, с автоматическим сохранением.
- Сразу раскрасить стандартные labels: praise — зелёный, nitpick — серый, suggestion — синий, issue — красный, todo — оранжевый, question — фиолетовый, thought — сиреневый, chore — серо-коричневый, note — бирюзовый. Новые пользовательские labels нейтральные до выбора цвета.
- Из одного выбранного оттенка получать согласованные фон, текст и рамку, читаемые в светлой и тёмной теме.
- Сохранять цвет при переименовании, сортировке и повторном открытии; применять общий цвет на всех поддерживаемых сайтах и обновлять открытые панели.
- Совместимо читать прежний список строк без потери текста, порядка и пустого списка.
- **BREAKING:** цвет текста, фона и рамки кнопки определяется label поверх CSS профиля, включая сохранённый и пустой CSS. Остальное оформление по-прежнему определяется профилем. Это согласованное изменение прежнего контракта полного CSS.
- Иконки labels, отдельная палитра для каждого сайта и визуальный конструктор CSS не входят в scope.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `popup-label-management`: выбор и хранение цвета, стандартная палитра и совместимость прежнего списка.
- `site-profiles`: цветные кнопки, обновление открытых панелей и приоритет цветов над CSS профиля.
- `options-page`: уточнение роли редактора CSS и поведения пустого CSS, независимость сброса профиля от цветов labels.

## Impact

Затрагиваются popup, content script, общий модуль модели labels/палитры и его подключение в manifest и worker; подсказка редактора CSS, README и docs/site-profiles.md. Потребуются тесты совместимости хранения, popup, content script, подключений ресурсов и браузерная приёмка. Новые зависимости, разрешения и сборщик не нужны. Основные спецификации обновляются после реализации, в этом change создаются только delta-specs.
