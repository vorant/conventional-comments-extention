## MODIFIED Requirements

### Requirement: Пользователь может вставить label в начало комментария

Расширение SHALL вставлять выбранный из отображаемой панели Conventional Comments label в начало текущего текста комментария. При включённых эмодзи и выбранном символе префикс SHALL иметь вид `<emoji> <label>: `, иначе `<label>: `. Символ SHALL быть обычным Unicode-текстом, а не глифом специального шрифта или ссылкой на ресурс расширения.

#### Scenario: Комментарий пустой

- **WHEN** пользователь нажимает label `suggestion` со стандартным символом при включённых эмодзи
- **THEN** поле комментария начинается с текста `💡 suggestion: `

#### Scenario: В комментарии уже есть текст

- **WHEN** пользователь нажимает label `question` со стандартным символом при включённых эмодзи в поле с уже введенным текстом
- **THEN** поле комментария начинается с текста `❓ question: `, а ранее введенный текст сохраняется после этого префикса

#### Scenario: Пользовательский label содержит emoji

- **WHEN** пользователь нажимает сохраненный label `idea💡` без отдельно выбранного эмодзи
- **THEN** поле комментария начинается с текста `idea💡: `

#### Scenario: Пользовательский label заменяет стандартный label

- **WHEN** пользователь переименовал `suggestion` в `proposal` выбрал «Без эмодзи» и нажимает label `proposal`
- **THEN** поле комментария начинается с текста `proposal: `

#### Scenario: Эмодзи отключены
- **WHEN** общий переключатель выключен либо у suggestion выбран пункт «Без эмодзи» и пользователь нажимает его кнопку
- **THEN** вставляется `suggestion: ` без лишнего начального пробела

#### Scenario: Читатель без расширения
- **WHEN** автор публикует комментарий с префиксом `💡 suggestion: `, а читатель открывает его без расширения и Nerd Fonts
- **THEN** эмодзи присутствует в опубликованном тексте и отображается средствами сайта или системы читателя

#### Scenario: Изменение настроек после вставки
- **WHEN** автор меняет выбранный символ или отключает эмодзи
- **THEN** уже опубликованные комментарии и текст открытого черновика автоматически не переписываются
