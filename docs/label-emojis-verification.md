# Приёмка label-emojis — 2026-09-24

Среда: macOS 26.7 (25G229), Google Chrome 153.0.8010.53, отдельный тестовый профиль и установленное unpacked MV3-расширение. Реальные service worker и chrome.storage.sync, popup.html открыт отдельной вкладкой с viewport 360×600 CSS px. Файлы расширения загружены через CDP Extensions.loadUnpacked; штатная CSP и minimum_chrome_version 102 сохранены.

## Проверено в браузере

- В новом профиле до первого открытия включён offline. Локальные ES-модули, русский i18n и каталог загрузились без сети; после очистки IndexedDB повторено построение базы. Все наблюдённые запросы popup — chrome-extension:// к его ресурсам. Ошибок JavaScript в повторном прогоне нет.
- Русский поиск «лампочка» находит 💡. Поиск «ракета» также находит космонавта; выбор стрелкой вниз и Enter сохранил полную последовательность 🧑‍🚀. Клик по результату тоже сохраняет выбор.
- Escape и «Назад» сохраняют прежний выбор и возвращают фокус к кнопке нужной строки. «Без эмодзи» удаляет символ и сохраняет отсутствие после нового открытия.
- Выключение флага отправлено worker, вкладка popup сразу закрыта. Worker завершил запись; новое открытие показало выключенный флаг. Индивидуальные символы сохранились и доступны для редактирования при выключении.
- Светлая и тёмная темы проверены визуально. Пикер занимает x=12…348, y=163…523 в viewport 360×600, поиск, категории, результаты, избранное и кнопки возврата доступны без горизонтального обрезания.
- Ошибка загрузки JSON смоделирована отклонением fetch при пустой IndexedDB. Показаны сообщение и «Повторить загрузку»; после восстановления fetch повтор открыл локальный каталог. Остальные настройки доступны через возврат.
- На подменённом локальной HTML-fixture GitHub PR URL работают два настоящих content-script редактора. Смена флага обновила существующие кнопки, сохранив textarea, черновик «Черновик», фокус и выделение [1,3]. После включения вставлен `💡 praise: Черновик`; штатный submit fixture передал этот текст в preview, reset восстановил исходный черновик.
- Текст preview перенесён как textContent в отдельную страницу браузера без расширения, без подключённых шрифтов и без content script. Unicode `💡 praise: Черновик` сохранился и отображается системным шрифтом.

## Автоматические проверки

Node-тесты проверяют v2/defaults, миграцию строк/v1 без записи при чтении, цвета, пустые списки, неизвестные версии, некорректные символы, ZWJ/флаги/тон кожи/variation selectors; согласованную очередь worker, quota/retry и поздние ответы; переключатель, дубликаты, переименование, перенос и отмену preview; позднее событие пикера после открытия другой строки; единый префикс textarea/rich-text, курсор, input и неподдерживаемые редакторы; динамические панели, независимость сбросов CSS/профилей, SPA, отзыв доступа и диагностику. Отдельный тест проверяет SHA-256 поставленных файлов, разрешение локальных импортов, русский каталог и лицензии.

## Границы

Это проверка установленного расширения на локальных fixtures, а не текущего живого DOM GitHub, GitLab, Bitbucket или корпоративных сайтов. Комментарии на внешние сайты не публиковались. На локальном contenteditable проверен реальный rich-text: составной префикс 👩🏽‍💻 note, сохранение жирного текста, одно событие input, отсутствие дубля и курсор UTF-16 14; штатные интеграции сайтов по-прежнему требуют ручной приёмки.
