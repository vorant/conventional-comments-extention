В отдельном профиле открыта публичная страница `https://github.com/react/react/pull/37636/files`. Без входа GitHub показывает Sign in; textarea и кнопки открытия комментария отсутствовали. Поэтому использован предусмотренный планом demo: снимок явно подписан на самой странице и в README. Он не подтверждает работу текущего DOM GitHub или корпоративных GitLab/Bitbucket.

Demo — собственная HTML-страница с английским примером `average(values)`, обычным form и textarea `name="comment[body]"`. Playwright локально перехватил URL `https://github.com/cc-demo/review/pull/1` и вернул этот HTML, чтобы штатный GitHub content script подключился через manifest. Панель, цвета и обработчик вставки не имитировались. В textarea введено `Return 0 when the list is empty to avoid dividing by zero.`, затем нажата настоящая кнопка `💡 suggestion:`. Проверено итоговое значение с префиксом. Submit на стенде ничего не отправляет; комментарии в GitHub не создавались.

Popup снят как страница расширения без изменения DOM/CSS и без масштабирования. Для company-settings через настоящий UI выбран GitLab, Site URL заменён на `https://git.company.example`, дождались Saved. Маска `/*/-/merge_requests/*` и селектор остались предустановленными. Кнопку Allow site access не нажимали: кадр честно показывает `No access. Allow site access to continue.`. Снимки не содержат приватного кода, пользовательских аккаунтов или внутренних адресов.

Для повторения: загрузить unpacked extension в чистый профиль, снять popup с viewport 360 × 462, настройки с viewport 800 × 900 и fullPage; demo с viewport 1280 × 800 и device scale factor 1. Снимать после загрузки шрифтов и сохранения полей. Store asset имеет квадратные углы и не содержит добавленных декоративных полей. PNG просмотрены; store asset дополнительно отображён в браузере размером 640 × 400 и проверен визуально.
